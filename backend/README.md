# XTRAKA Backend

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create `.env` from `.env.example` and fill values.
3. Start the server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev`: start with nodemon
- `npm run start`: start in production
- `npm run seed`: insert default tasks and settings
